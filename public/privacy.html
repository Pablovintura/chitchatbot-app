Privacy

Last updated October 28, 2026

The short version

ChitChatBot does its work on your computer. It does not send chat messages, what you type, or anything about you to us or to any server we run. We have no accounts and no analytics.

What the extension reads

  • Chat messages on kick.com, twitch.tv and YouTube live chat, so it can translate them for you.
  • If you turn on Write mode, the text you type in the chat box, so it can show a translated preview and send it.

It only runs on kick.com, twitch.tv and YouTube live chat pages and does not read any other site.

Where translation happens

Translation and language detection use the translator built into Chrome and Brave, which runs on your device. When you use a language pair for the first time, your browser downloads that language pack from its own provider. That download is made by your browser, not by ChitChatBot.

What is stored

Your settings (language, switches) are saved with the browser's extension storage. If you are signed in to Chrome with sync turned on, Chrome may sync these settings across your devices. Chat messages and translations are kept in memory while the page is open and are not saved.

Changes

If a future paid option sends text to a ChitChatBot server for better translation, it will be a separate opt-in, and this page will be updated before it exists.
